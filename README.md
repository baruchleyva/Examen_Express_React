# Examen_Express_React
Prueba técnica para el puesto Desarrollador Full Stack con Express para backend, React para frontend y PostgreSQL para la base de datos.

## Herramientas utilizadas
Front
 - React

Back
 - Node.js
 - Express
 - JWT
 - Postman
 - Api de Google Places API

## Configuracion y ejecucion del backend
1.- Clonar el repositorio desde la siguiente liga https://github.com/baruchleyva/Examen_Express_React.git
2.- Una vez clonado el reporitorio en la rama desarrollo se podran visualizar ambas partes del proyecto, el fronend y el backend
3.- En la rama basedatos se encontrara el script para la creacion de la base de datos junto a un seeder de los 50 registros que se solicitaron mas el administrador
4.- Para el el levantamiento de ambas partes se puede realziar desde visual studio code, en dos terminales, primero se ejecuta el back y despues el front
    4.1 .- Para back node index.js
    4.2 .- Para front npm start
